Doel: Bouw een volledig Applicant Tracking System (ATS) binnen Replit, gebruikmakend van beschikbare hosting- en databasediensten. Gebruik PostgreSQL (Replit DB of externe verbinding), HTML/CSS/JS voor frontend en eventueel Python of Node.js als backend. Houd rekening met uitbreidbaarheid, audittrail, en desktop-first gebruik.

1. 📦 
Algemene Architectuur
Frontend: Desktop-first layout in HTML, CSS (optioneel met Tailwind), JavaScript voor interactie


Backend: Gebruik Python (Flask/FastAPI) of Node.js (Express) – afhankelijk van Replit-voorkeur


Database: PostgreSQL (extern verbonden of via Replit DB)


Hosting: Replit project met publieke toegang, gebruik eventueel Secrets voor beveiliging



2. 🧱 
Data-entiteiten en relaties
Entiteiten:
Kandidaat


Opdrachtgever


Traject (verbindt kandidaat ↔ opdrachtgever)


Notitie


Document


Relaties:
Eén kandidaat ↔ meerdere trajecten


Eén traject ↔ één opdrachtgever


Eén traject ↔ één kandidaat


Notities en documenten kunnen gekoppeld zijn aan kandidaat, traject of opdrachtgever



3. 📊 
Datamodel (voorbeeld in SQL)
CREATE TABLE Kandidaten (
  id SERIAL PRIMARY KEY,
  datum_toegevoegd TIMESTAMP,
  naam TEXT NOT NULL,
  beschrijving TEXT,
  rijbewijs TEXT[],
  woonplaats TEXT,
  regio TEXT,
  marketing TEXT,
  telefoon TEXT,
  mail TEXT,
  status TEXT,
  fase TEXT
);

CREATE TABLE Opdrachtgevers (
  id SERIAL PRIMARY KEY,
  naam TEXT NOT NULL,
  contactpersoon TEXT,
  locatie TEXT,
  soort_werkzaamheden TEXT
);

CREATE TABLE Trajecten (
  id SERIAL PRIMARY KEY,
  kandidaat_id INT REFERENCES Kandidaten(id),
  opdrachtgever_id INT REFERENCES Opdrachtgevers(id),
  startdatum DATE,
  status TEXT,
  functie TEXT,
  tarief TEXT,
  opmerking TEXT
);

CREATE TABLE Notities (
  id SERIAL PRIMARY KEY,
  entiteit_type TEXT,
  entiteit_id INT,
  tekst TEXT,
  tijdstempel TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE Documenten (
  id SERIAL PRIMARY KEY,
  entiteit_type TEXT,
  entiteit_id INT,
  bestandsnaam TEXT,
  opslag_url TEXT,
  geupload_op TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
