# Applicant Tracking System (ATS) — Product Requirements Document

## Doel van de Applicatie

Dit ATS ondersteunt Nederlandse uitzendbureaus in de groenvoorziening bij het beheren van kandidaten, trajecten, opdrachtgevers, notities en documenten. De app is gebouwd in Replit met de volgende stack:

- **Frontend**: React 18, TypeScript, Tailwind CSS
- **Backend**: Node.js met Express
- **Database**: PostgreSQL via Neon
- **ORM**: Drizzle ORM
- **Authenticatie**: JWT + e-mail login, met drie rollen

---

## Gebruikersrollen

| Rol        | Rechten                                                  |
|------------|-----------------------------------------------------------|
| Viewer     | Alleen lezen, geen bewerkrechten                         |
| Recruiter  | Toevoegen/bewerken van kandidaten, trajecten, notities   |
| Admin      | Alle rechten, incl. gebruikersbeheer en toegang tot dashboard |

## Frontend Functionaliteiten

### Navigatie

- Sidebar met vaste routes: kandidaten, trajecten, opdrachtgevers, admin-dashboard

### Kandidatenbeheer

- Lijstweergave met filters (status, regio, rijbewijs)
- Modal voor toevoegen/bewerken
- Detailpagina met gekoppelde trajecten, notities en documenten
- Notities kunnen per kandidaat worden toegevoegd

### Trajectbeheer

- Modal voor toevoegen/bewerken van trajecten
- Koppeling met kandidaat en opdrachtgever
- Statusselectie en datumvelden

### Opdrachtgeverbeheer

- Lijst + modale invoer en bewerkopties
- Koppeling met trajecten via dropdown of ID

### Documentbeheer

- Documenten zichtbaar in kandidaat-profiel
- Bestanden kunnen nog niet worden geüpload (to-do)
- Types nog vrij (geen categorisatie enforced)

---

## Filtering & Sorting

- Collapsible filters op kandidatenlijst
- Multiselect rijbewijs-filter
- Client-side filtering met TanStack Query
- Sortering per kolom
- Paginering aanwezig

---

## Authenticatie & Beveiliging

- JWT-based login op basis van e-mail/wachtwoord
- Geen externe OAuth verplicht
- Rolgebaseerde toegangscontrole
- Login redirect op basis van rol (viewer, recruiter, admin)

---

## Technische Architectuur

### Frontend

- **React 18 + TypeScript**
- **Wouter** voor routing
- **TanStack Query** voor data en caching
- **Tailwind CSS** voor styling
- Responsive design voor mobiel, tablet en desktop

### Backend

- Node.js met Express
- RESTful API’s met JWT authenticatie
- Middleware per route voor rolverificatie

### Database

- PostgreSQL via Neon
- Drizzle ORM voor type-safe database interactie
