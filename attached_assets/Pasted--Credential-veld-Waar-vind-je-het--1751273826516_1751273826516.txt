| Credential / veld                                                              | Waar vind je het?                                                                                    | Wanneer verplicht?                                                             | Bron                 |
| ------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------ | -------------------- |
| **`company_account_id`**                                                       | Scoro → ⚙︎ *Settings › Integrations › Scoro API*                                                     | **Altijd** – elk request                                                       | ([api.scoro.com][1]) |
| **`apiKey`**                                                                   | Zelfde scherm, onder **API Key**                                                                     | Server-to-server authenticatie                                                 | ([api.scoro.com][1]) |
| **`user_token`**                                                               | Ophalen via endpoint **`/userAuth/modify`** (inloggen met gebruikersnaam + wachtwoord + device-info) | Wanneer je in naam van een specifieke gebruiker werkt (bijv. rechten, filters) | ([api.scoro.com][1]) |
| **Scoro-subdomein**                                                            | URL van je omgeving (bijv. `nosuch` → `https://nosuch.scoro.com/…`)                                  | In elke endpoint-URL                                                           | ([api.scoro.com][1]) |
| **`scoro-app-id`** (HTTP-header)                                               | Alleen nodig voor *publieke* marketplace-integraties                                                 | Optioneel voor interne projecten                                               | ([api.scoro.com][1]) |
| **2-stap-verificatie velden** (`verification_token`, `auth_method_code`, etc.) | Worden pas gevraagd als 2FA aanstaat                                                                 | Alleen bij login-flow                                                          | ([api.scoro.com][1]) |

[1]: https://api.scoro.com/api/v2 "Scoro API v2"
