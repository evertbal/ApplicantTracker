Tabellen en velden bestaan al:

- candidate.status & candidate.phase  
- trajectory.status

📄 Mapping traject → kandidaat-status  
| Trajectstatus           | Kandidaten-ATS-status              |
|-------------------------|------------------------------------|
| Geaccepteerd            | Beschikbaar / Direct beschikbaar   |
| Voorgesteld aan klant   | In bemiddeling                     |
| Gesprek met klant       | In bemiddeling                     |

| Niet geplaatst          | Nu niet beschikbaar                |
| Gestopt                 | Inactief                           |
